# Aditya S Maller — Personal Technical Website

Source code and web application for **Aditya S Maller**, AI/ML Research Engineer (SPIRE Lab, IISc & RV University).

## Overview

A high-signal personal website showcasing empirical machine learning research, full-stack AI system architectures, publications, and technical leadership.

- **Hero & Executive Summary**: Concise 20-30 second glanceable identity highlighting research at SPIRE Lab, IISc and key capabilities.
- **Technical Snapshot**: Grouped skills across AI/ML, Speech & Audio ML, Systems & Engineering, and Evaluation Methodologies.
- **Evidence Highlights**: 5 key pillars covering SPIRE Lab IISc, FastRAG async backend, adaptive decoding temperature research, quantum hallucination mitigation (Springer), and LightGBM malware detection.
- **Subpage Navigation**: Client-side routing for `/publications`, `/projects`, `/experience`, `/leadership`, `/competitions`, `/public-good`, `/entrepreneurship`, `/about`, `/references`.

## Tech Stack

- **Framework**: React 19 + Vite 7
- **Styling**: Vanilla CSS (CSS variables, dark/light themes, responsive grid)
- **Deployment**: Static build ready for GitHub Pages (`Aditya-Maller.github.io`)

## Local Development & Build

```bash
npm install
npm run dev
```

Build production static files:
```bash
npm run build
```
